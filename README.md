# Reaction Rate Test

A simple and elegant reaction time test built with React and Vite.

## Features

- **Reaction Timing**: Measures your reaction time in milliseconds.
- **Visual Feedback**: Dynamic background colors based on game state.
- **History**: Keeps track of your last 5 attempts.
- **Best Score**: Automatically identifies and displays your best reaction time.
- **Keyboard Support**: Use the Space key to start and interact.

## Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v18 or higher recommended)

### Installation

1. Clone the repository
2. Install dependencies:
   ```bash
   npm install
   ```

### Running the App

Start the development server:
```bash
npm run dev
```

The application will be available at `http://localhost:5173`.

## Build for Production

To create a production build:
```bash
npm run build
```
